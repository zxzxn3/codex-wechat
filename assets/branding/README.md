# Brand assets

The files in this directory are project identity assets. They are not licensed
under the Apache License 2.0 that covers the source code and documentation.

## Files

- `codex-wechat-pixel-mascots.png`: the same 768x768 GPT-generated image as
  `a-fat-fish/runs/deepseek-gpt-avatar/chat-window-avatar-768.png`, with the
  background changed from `#242424` to `#0057B8`. The character pixels are
  identical. The GPT output was based on a source image supplied by the user
  from Bilibili, so it is treated as an adaptation rather than an independent
  original work.
- `codex-wechat-wechat-contact.jpg`: WeChat contact-row screenshot using the
  avatar above.
