# Brand assets

The files in this directory are project identity assets. They are licensed
separately from the source code and documentation.

## Files

- `codex-wechat-pixel-mascots.png`: the same 768x768 GPT-generated image as
  `a-fat-fish/runs/deepseek-gpt-avatar/chat-window-avatar-768.png`, with the
  background changed from `#242424` to `#0057B8`. The character pixels are
  identical. The GPT output was based on a frame from the Bilibili video below,
  so it is treated as an adaptation rather than an independent original work.
- `codex-wechat-wechat-contact.jpg`: project-owned screenshot of the bridge's
  WeChat contact row, using the mascot above.
