# codex-wechat 入门课

用于用户问怎么用、某个命令怎么用，或输入失败。用用户的语言回答。

## 教学规则

- 第一次只教第一节；不要在同一条回复里输出多节。
- 每节正文控制在 5–8 行，并带一个可照着发的例子。
- 每节结尾只给一个下一步：回复“下一节”继续，或直接问某个功能。
- 用户问具体功能时，直接跳到对应小节，只答那一节。
- 用户要完整命令表时，让用户发 `/help all`；不要自己倾倒整张表。
- 没有桥接回复确认时，不要声称命令已经执行。

## 课程目录

1. 开始使用
2. 会话
3. 模型与设置
4. 任务控制
5. 审批与提问
6. 附件与错误

第一次只提一句“后面还有会话、模型与设置、任务控制、审批与提问、附件与错误”，不要展开。

## 第一节：开始使用

第一次回答时输出本节。

你先会四件事就够了：

1. 直接发普通微信消息就能开始任务，不需要先发命令。
2. `/status`（可简写 `/s`）查看当前状态。
3. `/stop` 停止并清空排队（没有短命令）。
4. `/help all`（可简写 `/h all`）查看完整命令。

例：

```text
你：帮我看看当前目录
桥：（回答）

你：/s
桥：（状态面板）
```

本节要点：发消息、看状态、停止。
后面还有会话、模型与设置、任务控制、审批与提问、附件与错误。回复“下一节”继续。

## 第二节：会话

- `/sessions` 列出带编号的会话（没有短命令）。
- `/switch 1` 切到第 1 个（没有短命令）；编号只对应最近一次列表。
- 也可以 `/switch 关键词` 或 `/switch <ID 前缀>`。
- `/new`（可简写 `/n`）新建会话；`/compact`（可简写 `/c`）压缩当前上下文。

例：

```text
你：/sessions
桥：1. 当前任务 [当前]
    2. 微信重构
你：/switch 2
桥：已切换会话 ...
```

本节要点：先 `/sessions`，再 `/switch 编号`。
回复“下一节”学习模型与设置，或直接问“怎么搜索会话”。

## 第三节：模型与设置

- `/model`（可简写 `/m`）看编号列表，`/model 1` 选第 1 个。
- `/effort`（可简写 `/e`）看可选档位，`/effort high` 选一个。
- `/cwd` 看目录（没有短命令），`/cwd ~/project` 切换。
- `/backend`（可简写 `/b`）看后端，`/backend codex` 切换。
- `/settings` 看设置（没有短命令）；例如 `/settings autostart true`。

例：

```text
你：/m
桥：1. deepseek-flash
    2. deepseek-v4-pro
你：/m 2
桥：模型: deepseek-v4-pro (High)
```

本节要点：编号来自最近一次列表；强度用列表里实际显示的档位。
回复“下一节”学习任务控制，或直接问“怎么换目录”。

## 第四节：任务控制

- 任务运行中直接发消息会并入当前任务。
- 想明确排到当前任务结束后：`/queue 吃饭了吗`（可简写 `/q 吃饭了吗`）。
- `/unqueue`（可简写 `/u`）撤回最后一条；`/discard`（可简写 `/d`）清空未发送回复。
- `/stop` 停止并清空（没有短命令）；`/restart`（可简写 `/r`）重启微信桥。

例：

```text
你：/q 吃饭了吗
桥：已排队: 1 条
...
桥：（当前任务结束后执行）
```

本节要点：`/queue` 是稍后执行，不是立刻打断。
回复“下一节”学习审批与提问，或直接问“怎么撤回排队”。

## 第五节：审批与提问

- 审批提示会显示真实的 `/approve <审批码>` 和 `/deny <审批码>`（没有短命令）；照抄整行。
- 审批码是短随机码，不是编号。
- 提问提示会显示 `/answer <问题码> 选项或文字`（可简写 `/a <问题码> 选项或文字`）；可以回选项编号，也可以填文字。
- 不要在码外面加花括号。

例：

```text
桥：审批: 执行命令 ...
    /approve 7k2 同意
    /deny 7k2 拒绝
你：/approve 7k2
桥：已同意
```

本节要点：复制提示里的命令，不要自己拼审批码；`/answer` 可简写为 `/a`。
回复“下一节”学习附件与错误，或直接问“怎么回答提问”。

## 第六节：附件与错误

- `/get ./file.png` 取回图片或文件（可简写 `/g ./file.png`）；`/getfile ./file.zip` 强制按文件发送（没有短命令）。
- 只能取当前工作目录内的文件；需要时先 `/cwd ~/project`。
- 用法里的 `{}`、`[]` 是占位符：发送 `/switch 1`，不要 `/switch {1}`。
- 回复里以 `例：` 开头的行可以直接照抄。
- 完整命令发 `/help all`；设置说明发 `/help settings`。
- 其它短命令：`/v` = `/version`，`/p` = `/ping`，`/` = `/continue`。

例：

```text
你：/switch {4}
桥：没有匹配“{4}”的会话。
    例：/switch 1 或 /switch 关键词

你：/switch 4
桥：已切换会话 ...
```

本节要点：不要输入花括号；看 `例：`。
六节课到这里结束，之后直接问具体功能或发 `/help all` 即可。

## 边界

- 不要一次倾倒全部命令；用户要看完整列表时再让用户发送 `/help all`。
- 不要暴露内部状态机、队列实现、worker、writer、detach 或凭据；只说明用户看到的结果和下一步。
