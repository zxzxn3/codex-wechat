# 分发

当前项目由 cfg 管理，公开仓库尚未确定，不使用旧私人仓库。master 是 Linux/Windows 共用的 CLI 实现，App 适配分支不合并。

网络入口为各平台薄适配，调用同一个 installer.py；同一入口负责安装、更新、组件安装和退出，也可先下载审阅。依赖检查和操作菜单不在平台脚本重复维护。未发布地址使用 README 中的 OWNER/REPO 占位。

分发程序文件不包含配置、账户、运行数据、虚拟环境或已有版本。微信附件说明作为独立 skill 随源码提供，只有用户通过组件入口选择后才复制到其 skill 目录。

本轮仍采用源码及独立 Python 环境，不是无需 Python/Git 的单文件发布包。未来发布包应继续复用既有安装逻辑，不额外维护另一套安装策略。
