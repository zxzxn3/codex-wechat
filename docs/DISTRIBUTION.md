# 开发与分发

Linux与Windows从同一个项目库开发，不复制两份长期演化的源码。重构前Windows源码已留存
在本地archive/windows-development分支；临时交接清单不进入发行载荷。cfg与项目的最终归属
迁移独立处理，不把整个dotfiles库推送为项目。

源码不包含config、账户、.state、共享后台记录、日志、虚拟环境或已有版本。平台网络入口
调用同一个安装器，安装策略不在PowerShell/Bash里复制。requirements版本与工具缺失策略
集中维护；原生QR可用时不安装Python QR回退。附加skill由组件菜单显式安装。

本轮采用源码与版本独立Python环境，Git用于开发与在线获取源码。新版本按自身清单计算身份，
更新不能用新排除规则重定义旧版本。来源记录与current一致，同版无变化不重写来源。
旧版本可能仍被进程使用，不作为临时垃圾自动删除；本次下载、构建和原子写临时文件均清理。
