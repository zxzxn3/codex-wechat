# 开发与分发

Linux源码由cfg跟踪，项目目录不长期保留独立.git。对外更新时从已跟踪的项目文件
导出到临时Git工作区，核对不含私有数据后提交推送；GitHub项目库不包含cfg其它配置。
Windows继续开发时从同一远端取得源码，切换开发环境前先同步，避免两份未同步源码分叉。

本次重构前Windows源码留存在远端归档分支，活动源码只保留统一实现。临时交接清单不
进入发行载荷，用户账户、状态、代理、工作目录与源码分开，不作跨系统运行状态同步。

平台网络入口调用同一个安装器；依赖策略集中在installer.py，版本集中在requirements。
原生QR可用时不安装Python回退。附件skill由组件入口选择安装。安装不初始化账户、不
默认开启自启、不启动或重启桥接；更新保留配置和已有自启状态。

新旧版本按各自清单验证，不用新排除规则重定义旧版身份。本次下载、构建和原子写临时
文件均清理；仍可能被进程使用的旧版本和已保存的附件不作为临时垃圾自动删除。
