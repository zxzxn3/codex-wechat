# 复杂度与可选取舍

2026-11-02。基于本轮实现；行数是源码体量，不是工时或维护难度测量。下面的成本判断是
结构性估计，不能当成精确预算。所有删除选项均需用户决定，本轮不据此取消能力。

## 复杂度主要在哪里

| 部分 | 维护难度 | 原因 | 放弃或简化会得到什么 |
| --- | --- | --- | --- |
| 桌面活动会话接管 | 高 | 多客户端共享后台、早到/迟到事件、请求归属、轮次竞争、App内部接口版本 | 不接管桌面活动会话会显著减少运行时边界，但手机与桌面不能继续同一正在工作的会话 |
| 可靠交付与重连 | 高 | 接受状态不确定、崩溃恢复、重复消息、输出顺序和部分失败 | 简化能减代码，但代价是丢消息/重复执行；不建议为减负牺牲这些边界 |
| 自写安装/更新 | 高 | 一行入口、依赖环境、版本构建、旧版清单、稳定入口、跨平台服务注册 | 改用成熟发行/安装工具可省维护；也会改变此前选定的安装体验和依赖条件 |
| Windows后台托管 | 中高 | 任务计划、Win32进程/Job Object、单实例、退出码和原生通知 | 放弃整个Windows平台收益大；仅放弃Windows App不会消除这部分 |
| 图片/文件双向传输 | 中高 | CDN、加解密、快照、权限、大小和部分失败 | 只保留文字可明显简化；仅去掉回传仍需保留接收和CDN/解密 |
| 重绑与认证失效 | 中 | 服务与扫码互斥、同身份刷新、换身份隔离、部分提交失败 | 可简化自动编排为人工停服务/扫码/启动，但提醒和身份隔离仍必要 |
| 原生问题/审批 | 中 | 请求只属于实际接收的连接，桌面/微信可能竞争回答 | 可只允许桌面回答；离开电脑时遇到问题可能无法推进 |
| 切片、模板、状态、测速 | 低至中 | 主要是纯函数和已有快照，网络测速另有子进程 | 删除会减少少量代码，通常不触及最难维护的部分 |
| 后端切换、模型/目录等命令 | 低至中 | 大部分复用同一原生协议 | 单独删除DeepSeek入口或某个短命令，维护收益很小 |

安装器本体约1200行，Windows supervisor约500行；它们比单独的App路径发现更值得审视。
“把14行依赖声明另拆模块”曾让单文件网络引导无法导入，已撤销这次不值得的拆分：
声明集中在安装器，原生发现实现按需复用，而非为了文件划分制造启动依赖。

## 四种组合不能独立平分

调用App内置codex执行程序，与接管App窗口正在使用的会话，是两个层级。
前者复用CLI的App Server协议；后者还需要让两个客户端接入同一后台。
用户在Windows的成功结果支持前者，并有共享接入的既往使用证据；不能扩大为所有版本等价。

按当前约8400行生产源码粗分（排除测试、文档、归档和experiments）：

| 文件归属 | 约行数 | 占比 |
| --- | --- | --- |
| 两平台共用文件 | 6900 | 82% |
| Windows专用文件 | 1300 | 16% |
| Linux专用文件 | 200 | 2% |

这是按文件归属分类，共用文件中仍有少量平台分支；Windows专用包含微信服务托管和安装，
不能全部算作Codex Windows接入。重构前Linux生产源码约7600行、Windows约7400行；
本轮统一能力后约8400行，总代码没有减少，减少的是分叉维护与重复责任。

| 组合 | 真正新增或独有的负担 | 单独放弃的收益 |
| --- | --- | --- |
| Linux CLI | 主要基线；原生daemon、Unix socket、systemd接入 | 若仍保留Linux App，系统服务和大部分协议代码都不能删 |
| Linux App | 路径发现很薄；App共享使用公共desktop/WS代码，平台独有部分只有几十行 | 单独放弃只省少量代码；若Windows App仍在，共享逻辑仍要维护 |
| Windows CLI | 共用协议；原生exe发现、Windows托管、可选管道WebSocket约100行 | 若Windows App仍在，托管/安装/配置仍要维护；不能省掉整个Windows层 |
| Windows App | 内置exe发现、App入口、必要的回环后台；约百余行平台专有代码加公共共享逻辑 | 比删除Linux App更有收益，但Windows服务成本仍在，内部接口维护减少较明显 |

四行互相重叠，不能相加成100%。App共享的实际维护成本高于其独有代码占比，尤其在版本更新时。

## 可选的减负方向

1. **保留App内置运行时，取消桌面App会话接管。** 不强迫App用户另装CLI；微信仍使用相同
   Agent能力，但不保证桌面App窗口显示手机的实时对话。可删共享App入口和相关后台管理。
2. **只支持Linux。** 能省掉完整Windows服务/安装/进程层及实机验证矩阵，收益最大；Windows不能使用。
3. **只保留文字。** 能省掉大部分媒体协议与文件交付边界，功能损失也直接。
4. **简化自写安装/更新体系。** 值得另作设计取舍，不在本次借重构静默推翻已批准的安装规则。

单独去掉Linux App、某个短命令、模板变量或DeepSeek后端名称，不是显著减负点。
