# 开源发布检查清单

> 适用场景：发布 codex-wechat 新版本，或首次公开仓库。
> 最近审计：2026-11-10。

## 当前结论

- [x] `LICENSE` 使用 Apache License 2.0。
- [x] README、安装文档和 bootstrap 使用无需认证的公开安装入口。
- [x] `NOTICE`、`TRADEMARKS.md` 和品牌素材说明已存在。
- [x] mascot 与 Apache-2.0 代码分开，按 CC BY-NC-SA 4.0 标注来源和修改。
- [x] 微信联系人截图已由项目维护者审阅并接受公开。
- [x] 已接受保留现有开发标签和分支引用。
- [ ] 发布前仍需完成干净副本、历史扫描和品牌素材复核。

## 发布门

- [ ] 对完整历史运行密钥和隐私扫描。
- [ ] 确认 `.env`、`config.json`、`.state/`、`logs/`、`workspace/`、`releases/`、
      私钥和证书从未进入任何提交。
- [ ] 检查提交作者和提交者邮箱是否符合公开意愿。
- [ ] 检查其余截图、二维码、路径和终端输出不包含未获同意公开的个人信息。
- [ ] 确认代码、Logo、角色图片、字体和图标有权随仓库发布。
- [ ] 完成传递依赖、Windows 运行时和随包字体的许可证审计。
- [ ] 接受外部贡献前确定 DCO 或 CLA。
- [x] 保留现有开发标签和分支引用，并接受其进入公开历史。
- [ ] 增加 `SECURITY.md`、贡献指南和支持渠道。
- [ ] 检查 Actions 权限、第三方 Action 固定版本和依赖告警。

## 安装与发布

- [ ] 在全新 Linux 用户环境测试安装、启动、更新和卸载。
- [ ] 在全新 Windows 用户环境测试安装、启动、更新和卸载。
- [ ] 验证公开 raw 地址、仓库 clone 和更新源无需 GitHub 登录。
- [ ] 验证安装失败、网络失败和重复安装不会破坏已有数据。
- [ ] 重新 clone 一个干净副本，运行完整测试、`ruff` 和安装烟测。
- [ ] 检查 GitHub 许可证识别、README 渲染、图片和 Actions 状态。
- [ ] 发布后继续监控 secret scanning、issues 和安全报告。
