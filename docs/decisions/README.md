# 决策记录索引

本目录保存已作出的产品与架构决策。当前行为以对应实现和
[COMMANDS](../COMMANDS.md)、[ARCHITECTURE](../ARCHITECTURE.md)、
[PLATFORMS](../PLATFORMS.md) 为准。

状态词：

- **提议**：尚未生效，允许修改。
- **暂未决策**：已记录问题和当前行为，但尚未选定产品语义。
- **已生效**：当前实现和文档应遵循。
- **已废弃**：不再适用，但保留历史理由。
- **被替代**：由另一条决策取代，需写明替代文件。

| 文件 | 决策主题 | 状态 | 更新时间 | 影响范围 |
| --- | --- | --- | --- | --- |
| [COMMANDS-DECISIONS](COMMANDS-DECISIONS.md) | 入口、命令语义、投递语义、安全与权限；2026-11-10 复核并补充安装布局与关闭决策 | 已生效 | 2026-11-10 | 命令面、交付、权限、安装布局 |

## 新增决策

1. 在 `docs/decisions/` 新建主题文件，文件名使用英文和连字符；新增文件建议小写。
2. 文件头写清更新时间、状态、影响范围和替代关系。
3. 在本索引增加一行；如果替代旧决策，同时更新旧文件的状态。
4. 更新相关文档链接，并运行 `scripts/reference_docs.py --check` 和文档测试。
